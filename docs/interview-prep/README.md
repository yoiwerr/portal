## 使用建议

1. **按顺序阅读** — 每篇文档有依赖关系
2. **看完一篇默写要点** — 输出是最好的记忆
3. **重点标 ⭐ 的必须能脱稿讲** — 这是面试必问
4. **睡前过一遍 05** — 面试高频问题心中有数

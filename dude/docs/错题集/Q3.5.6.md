# Q3.5.6 子图 token 能冒泡到外层 astream_events 吗

> **状态**：？？？ | **考点**：LangGraph 架构限制

## 正确答案

**不能。** `create_react_agent` 是 LangGraph 的预编译**子图**，它的 token 流式事件不冒泡到外层图的 `astream_events`——这是 LangGraph 的设计，不是 bug。

外层 `astream_events` 只能看到**本层节点**（planner/checkpoint/reflect）的 LLM 事件，看不到 execute 内部子图的 token。

## 关键解析

这是当初 SSE 实现失败的**根本原因**（见 `docs/to_log/debug-report-2026-07-14.md`）。最后放弃 token 级流式，改成 `graph.ainvoke()` 直接拿结果，流式降级为**节点级**（`session → execute/clarify → done`）。

要恢复 token 级流式，唯一正解是把 ReAct Agent 从 `execute_node` 内部**提到外层图作为独立节点**，这样它的事件才属于"本层"。

## 面试一句话

> 不能。create_react_agent 是子图，token 不冒泡到外层 astream_events，这是 LangGraph 的架构限制。所以我从 token 级流式降级成了节点级流式，用 ainvoke 直接拿结果。要恢复 token 级，得把 ReAct 提到外层图当独立节点。

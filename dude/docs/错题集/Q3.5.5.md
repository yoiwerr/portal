# Q3.5.5 ReAct 循环有轮数上限吗

> **状态**：❌ 答错 | **考点**：两套轮数限制搞混了

## 你的答案

> 有循环次数的 count 在 check 和 reflect 处

## 正确答案

你把**两套限制搞混了**：

1. **质检重试**（你答的）：`MAX_CHECKPOINT_RETRIES=1`、`MAX_REFLECTION_RETRIES=2`（`graph.py:54/50`），管的是"语义对齐/质量不过关 → 重跑 execute"，这是 checkpoint/reflect 的循环。
2. **ReAct tool 轮数上限**（题目问的）：配置是 `max_tool_rounds=10`（`config.py:42`），但 `execute_node` 创建 `create_react_agent` 时**没传这个值，也没传 `recursion_limit`**（全代码 0 命中）。所以实际兜底是 LangGraph 默认 recursion limit，不是你以为的 10 轮。

## 关键解析

`tool-loop-prevention.md` 里描述的 loop_guard 防打转机制是**设计稿，没落地**。这是"配置写了、代码没接上"的典型。

## 面试一句话

> 有两套限制别混：check/reflect 的重试次数是质检回环（1/2 次）；而 ReAct 的 tool 轮数上限 max_tool_rounds=10 其实没传进 create_react_agent，实际靠 LangGraph 默认 recursion limit 兜底。这是个配置和代码脱节的点。

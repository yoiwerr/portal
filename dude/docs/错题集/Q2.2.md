# Q2.2 AgentState 挂了哪些字段

> **状态**：？？？ | **考点**：共享状态 + reducer 机制

## 正确答案

`AgentState` 是 LangGraph 的共享状态字典（`TypedDict`，`core/graph.py:127`）。所有节点读写它、自动在节点间传递。

字段：`messages`、`module`、`background`、`extra_context`、`expressed_dimensions`、`clarify_round`、`plan`、`rag_context`、`enriched_query`、`tool_results`、`output`、`reflection_count`、`intent`，三层上下文（`l1_raw/l2_summary/l3_facts/last_turn_summary/turn_count`）、`engineering_context`、多 Agent（`multi_agent_perspectives/synthesis`）、checkpoint 反馈（`checkpoint_feedback/checkpoint_retry_count`）、执行进度（`completed_steps/execute_round`）、`user_id/session_id`。

## 关键解析

1. **没有"节点私有变量"**——state 就是共享机制。别掉进"哪些是临时值"的坑。
2. **`messages` 是唯一用 reducer（`add_messages`）的字段**：写入时**追加**，其他字段写入**覆盖**。
3. "临时"体现在**生命周期短**：`checkpoint_feedback` 只在质检回环里短暂存活，`rag_context` 在 rag 节点写、planner/execute 读。

## 面试一句话

> LangGraph 的 state 是全局共享字典，没有严格意义的节点私有变量；区别在于 `messages` 用 reducer 追加、其余字段覆盖式写入，部分字段生命周期很短。

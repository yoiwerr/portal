# Q3.4.3 scope.out 为什么比 in 更重要

> **状态**：？？？ | **考点**：负空间边界 + 空 out 的惩罚

## 正确答案

scope.out 是"不要做什么"，定义的是任务的**负空间边界**，防止执行时范围无限膨胀。它比 in 更重要，是因为"做什么"容易说清，但"不做什么"才是防失控的关键。

所以规则是：**scope.out 为空是最大风险信号，`contract.confidence` 至少减 0.2**（`system_prompts.py:161`）。

## 关键解析

这是"边界约束"的思想：一个没有"不做什么"的任务，执行 Agent 可能越界（用户说"做个登录"，它把 OAuth、找回密码、权限管理全做了）。负空间约束比正空间清单更能防止范围蔓延。

## 面试一句话

> scope.out 定义的是负空间边界，防执行范围膨胀。空 scope.out 意味着没有边界约束，是最大风险信号，所以契约 confidence 至少减 0.2。

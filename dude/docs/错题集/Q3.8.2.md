# Q3.8.2 25 个测试覆盖了什么

> **状态**：？？？ | **考点**：自己项目的测试必须知道

## 正确答案

25 个测试分两块：

- **`test_graph.py`（21 个）**：维度合并、完整度计算、追问生成、JSON 解析、降级逻辑——这些是**确定性部分**。
- **`test_session_store.py`（5 个）**：Session CRUD、消息读写、级联删除、反馈统计。

**故意不测的**：LLM 生成内容的"正确性"——不可测，靠 checkpoint/reflect 质检节点 + 人工监控兜底。

## 关键解析

这道题"不知道测了什么"是大忌。测试是你自己写的、项目里的核心证据之一，面试官问"你测试覆盖了什么"必须张口就来。核心策略一句话：**测确定性部分、监控非确定性部分**。

## 面试一句话

> 21 个在 test_graph.py，测维度合并、完整度、追问生成、JSON 解析、降级逻辑这些确定性部分；5 个在 test_session_store.py，测 Session CRUD、级联删除、反馈统计。故意不测 LLM 生成内容的正确性——那不可测，靠质检节点和人工监控。

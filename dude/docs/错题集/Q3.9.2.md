# Q3.9.2 embedding 整体挂了，完整降级链怎么串

> **状态**：？？？ | **考点**：逐环节"降级不崩溃"

## 正确答案

每个依赖 embedding 的环节都有本地兜底：

1. **RAG dense 检索**：`query` 的 except 兜底，`query_formatted` 再降级 legacy collection（`domain_knowledge`），最后返回"未找到知识"话术。
2. **L3 事实提取**：LLM 提取失败 → 降级正则规则提取（`_extract_atomic_facts`）。
3. **L3 事实召回**：embedding 算不出向量 → 降级内存字典关键词匹配（`_retrieve_facts_memory`）。
4. **UserProfile / SessionMemory 写入**：失败只记日志，不阻断主流程。

整体原则：**降级不崩溃**——最坏情况就是"没有知识库参考、基于通用知识回答"。

## 关键解析

这道题考的是你有没有把"每处的 try/except 降级"串成一条完整的降级链。每个外部依赖（embedding/rerank/LLM）都要有"挂了怎么办"的答案。

## 面试一句话

> RAG 检索失败走 except 兜底或降级 legacy collection，最后返回"未找到知识"；L3 提取降级正则规则、召回降级内存关键词；画像/摘要写入失败只记日志。整体是降级不崩溃，最坏就是没有知识库参考、基于通用知识回答。

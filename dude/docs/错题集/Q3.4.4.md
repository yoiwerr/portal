# Q3.4.4 JSON 三层降级分别是什么

> **状态**：❌ 答错 | **考点**：解析手段降级，不是内存降级

## 你的答案

> json 解析降级输出，因为会出现输出过长，处理的时候内存不足，需要逐渐降级处理，第四层直接返回 json 原文

## 正确答案

三层降级是**解析手段**的降级，跟"内存不足"无关：

1. `json.loads(content)` 直接 parse
2. 抠 ```` ```json ... ``` ```` 代码块再 parse
3. 正则 `\{.*\}` 抠第一个 `{...}` 再 parse

第 4 层兜底返回 `{"is_complete": False, "completeness": 0.3, ...}`——**故意让 `is_complete=False`**，把流程推向"追问用户"，而不是崩溃，也不是"返回 json 原文"。

## 关键解析

目的：LLM 即使开了 `response_format={"type": "json_object"}`，仍可能给 JSON 外包 markdown 代码块、或加"好的，这是结果："的前缀。三层逐级放宽"从整串必须是 JSON"到"只要里面有一段 JSON"。

## 面试一句话

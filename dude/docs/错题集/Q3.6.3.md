# Q3.6.3 命中多场景时 mode 怎么定

> **状态**：？？？ | **考点**：取最高等级

## 正确答案

取所有命中场景里的**最高等级**。按 level 降序排，`max_level≥3` 就 block、`≥2` 就 confirm、否则 suggestion（`engineering_advisor.py:161-171`）。

木桶最高板，不是平均——只要有一条阻断级风险就整段阻断。

## 关键解析

`advisories.sort(key=lambda a: a["level"], reverse=True)` 先降序，再 `max_level = max(...)` 取最高，最后按最高等级定 mode。这是"宁可误伤、不可漏放"的安全取向。

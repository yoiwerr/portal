# dude 可编译的人工技术笔记

只放维护者已筛选、适合所有用户的通用技术知识。文件名使用小写英文连字符，例如 `small-websites.md`。
记录原始出处、适用范围、整理日期、冲突和未知信息。不要放用户对话、项目方案、账号、密钥或旧知识库整库导出。

管理员运行 `python -m wiki_tools.cli ingest-note small-websites` 后才进入来源集合。扫描整个仓库、用户上传或任意 URL 导入均不支持。
两篇既有默认建议保留在 `wiki/defaults.md`、`wiki/access-and-data.md`；`init` 明确将它们作为人工来源快照。

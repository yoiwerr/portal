# Q3.5.4 3 个工具为什么不分配给任何 skill

> **状态**：❌ 答错 | **考点**：定位问题，不是预留

## 你的答案

> 这个是后续版本要用的，现在还在考虑具体拓展哪些能力，所以暂时没有使用这些 tool

## 正确答案

**是定位问题。** 阿福的定位是"协作引导者"而非"执行者"，所以 `python_exec`（跑代码）、`run_shell_preview`（跑 shell）、`write_file`（写文件）这三个"动手"工具**故意不暴露给任何 skill**，避免它越界替用户干不可逆的活。`tools/__init__.py:17` 注释写得很清楚。

## 关键解析

这三个工具在 `ALL_TOOLS` 里，但 `SKILL_TOOL_MAP` 里没有任何 skill 引用它们。这不是"还没想好"，而是刻意的能力边界——一个只该给建议的 Agent，不该有写文件、跑命令的权限。

## 面试一句话

> 是定位问题，不是预留。阿福是协作引导者不是执行者，所以跑代码、跑 shell、写文件这三个"动手"工具故意不进任何 skill 的白名单，避免越界干不可逆的活。

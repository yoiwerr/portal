# Q4.1 100 用户并发，哪里先出问题

> **状态**：？？？ | **考点**：内存 / 连接 / 连接数 / 外部 API 四点

## 正确答案

先炸的四处，各配一个改法：

1. **ContextEngine 内存字典**：单进程 `dict`，多实例部署不共享、并发下有锁竞争 → 换 Redis。
2. **PGVector 单连接**：`self.conn` 懒加载、非连接池，并发请求排队 → 换连接池或异步驱动。
3. **SSE 长连接**：占满 worker → 加连接上限。
4. **embedding/rerank 外部 API**：无并发限流 → 加限流 + 重试。

## 关键解析

这是"从单用户到多用户"的经典拷问，考你有没有意识到：内存态、连接态、长连接、外部依赖，这四类东西在多用户下都会暴露问题。单用户开发时它们都不是问题。

## 面试一句话

> 先炸的是内存字典（单进程 dict 多实例不共享、并发锁竞争，换 Redis）、PGVector 单连接（换连接池）、SSE 长连接占满 worker（加连接上限）、外部 API 无限流（加限流重试）。

# Q3.6.1 三级输出模式，分级依据

> **状态**：？？？ | **考点**：建议/确认/阻断，按风险分级

## 正确答案

三级（`engineering_advisor.py:27`）：

| level | mode | 行为 |
|---|---|---|
| 1 | 建议 suggestion | 注入上下文，不打断 |
| 2 | 确认 confirm | 暂停，问用户确认 |
| 3 | 阻断 block | 硬停，不执行 |

分级依据是**风险等级**，不是重要程度——风险越高越往上走，从"默默提一句"到"停下来问"再到"直接叫停"。

## 关键解析

每个内置场景预设了 `risk_level` + `output_mode` 的映射：API 密钥 → block，Git 公开提交/数据库操作/文件删除 → confirm，Python 依赖/部署 → suggestion。

## 面试一句话

> 三级是建议/确认/阻断，按风险等级分级不是按重要程度。风险越高越往上，从"注入不打断"到"暂停确认"再到"硬阻断"。

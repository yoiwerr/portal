# Q3.5.3 bind_tools 和 create_react_agent 各自干什么

> **状态**：？？？ | **考点**：挂 schema vs 编译循环

## 正确答案

- **`bind_tools(tools, parallel_tool_calls=True)`**：把工具 schema 挂到模型上，告诉它"你能调这些函数"；`parallel_tool_calls=True` 允许一轮同时发多个 tool call。
- **`create_react_agent(model, tools, prompt)`**：用这个绑好工具的模型，编译一个循环图：LLM 推理 → 调工具 → 看结果 → 再推理，直到输出纯文本或到轮数上限。

## 关键解析

两步关系：`bind_tools` 只改变模型（让它能"想调工具"），`create_react_agent` 才真正搭起"推理-行动"的循环框架。前者是"给模型发武器清单"，后者是"造一个会用武器打仗的循环"。

## 面试一句话

> bind_tools 是把工具 schema 挂到模型上、允许并行 tool call；create_react_agent 是用这个模型编译一个"推理→调工具→看结果→再推理"的循环图。前者给武器、后者造循环。

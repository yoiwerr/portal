## 一、Execute 节点的架构

Execute 是真正"干活"的节点。它使用 LangGraph 的 `create_react_agent` 创建一个工具调用循环：

```
用户消息 + System Prompt + 工具列表
        │
        ▼
┌──────────────────────────────────┐
│  ReAct Agent Loop                │
│                                  │
│  Thought → Action → Observation  │
│       ↑                   │      │
│       └───────────────────┘      │
│        (循环直到输出最终答案)      │
└──────────────────────────────────┘
        │
        ▼
   最终输出 (Markdown)
```

---

## 二、System Prompt 组装

Execute 节点的 System Prompt 由**多层拼接**而成：

```python
full_system_prompt = f"""{skill_system}      ← Skill 专属 Prompt (如 PROMPT_REFINER_SYSTEM)

{EXECUTOR_SYSTEM_PROMPT}                      ← Executor 通用 Prompt (含阿福身份)
{progress_text}                               ← 执行进度 (重试时显示已完成步骤)
{exec_context_block}                          ← 🔴 锁定意图 + 三层上下文
{contract_block}                              ← 任务契约 (scope/constraints/acceptance)
## 当前任务的上下文
- 目标: {plan.get('goal')}
- 执行步骤: {execution_plan}

## 用户背景
{background}

## 知识库参考
{rag_context}

## 额外上下文
{extra_context}

## 用户原始需求
{message}
"""
```

## 三、ReAct Agent 创建

```python
# 并行 tool call: 如果底层模型支持，同一轮可输出多个 tool_call
parallel_model = model.bind_tools(tools, parallel_tool_calls=True)

react_agent = create_react_agent(
    model=parallel_model,
    tools=tools,                    # Skill 专用工具子集
    prompt=full_system_prompt,
)

result = await react_agent.ainvoke({
    "messages": [HumanMessage(content=message)]
})
```

## 四、输出提取

```python
# 从 ReAct Agent 的输出中提取最终文本
output_messages = result.get("messages", [])

# 1. 提取用量元数据（最后一个有 usage_metadata 的 AI 消息）
for m in reversed(output_messages):
    if hasattr(m, "usage_metadata") and m.usage_metadata:
        _record_usage_from_response(state, m)
        break

# 2. 提取最终输出（最后一个有内容的 AI 消息）
for m in reversed(output_messages):
    if isinstance(m, AIMessage) and m.content:
        output = m.content
        break

# 3. 提取工具调用记录
for m in result.get("messages", []):
    if hasattr(m, "tool_calls") and m.tool_calls:
        for tc in m.tool_calls:
            tool_results.append({
                "name": tc.get("name", "unknown"),
                "args": tc.get("args", {}),
            })
```

## 五、执行进度追踪

当从 checkpoint/reflect 重试时，Execute 会知道已经完成了哪些步骤：

```python
completed = state.get("completed_steps", []) or []
execute_round = state.get("execute_round", 0)

if completed:
    progress_text = (
        f"## 📍 执行进度（第 {execute_round} 轮）\n"
        f"已完成步骤: {', '.join(completed)}\n"
        f"如果上述步骤的结果仍然有效，不要重复执行——直接从下一步继续。"
    )

# 执行完后更新进度
plan_steps = plan.get("execution_plan", [])
new_completed = list(completed)
for step in plan_steps:
    if step not in new_completed:
        new_completed.append(step)

return {
    "output": output,
    "tool_results": tool_results,
    "completed_steps": new_completed,
    "execute_round": execute_round + 1,
}
```

## 六、降级路径

ReAct Agent 失败时有两种降级：

```python
try:
    react_agent = create_react_agent(model=parallel_model, tools=tools, ...)
    result = await react_agent.ainvoke(...)
    output = extract_output(result)

except Exception as e:
    # 降级1: 使用旧版 Skill.execute() (直接 LLM 调用，无工具)
    if skill_instance:
        output = await _execute_legacy_skill(skill_instance, state, model)
    # 降级2: 返回错误信息
    else:
        output = f"执行出错: {str(e)}"
```

### 旧版 Skill 执行

```python
async def _execute_legacy_skill(skill_instance, state, model):
    from skills.base import SkillContext

    context = SkillContext(
        original_message=msg_text,
        expressed_dimensions=state.get("expressed_dimensions", {}),
        background=state.get("background", ""),
        rag_context=state.get("rag_context", ""),
        extra_context=state.get("extra_context", ""),
        completeness=state.get("completeness", 0),
    )
    return await skill_instance.execute(context, model)
```

## 九、Execute 与 Skill 的关系

```
Execute 节点
    │
    ├─ 正常路径: LangGraph create_react_agent
    │   ├─ System Prompt: Skill System + Executor System
    │   ├─ Tools: get_tools_for_skill(skill_name)
    │   └─ 输出: ReAct Agent 的最终回答
    │
    └─ 降级路径: skill_instance.execute()
        ├─ 纯 LLM 调用 (无工具)
        └─ 输出: Skill 的直接回答
```

> 当前 4 个 Skill 都使用 ReAct Agent 路径（因为 `execute_node` 优先创建 react_agent）。旧版 `skill_instance.execute()` 仅作为降级。

## 十、关键要点

1. **ReAct Agent 是执行引擎** — Tool calling 循环由 LangGraph prebuilt 管理
2. **System Prompt 多层拼接** — Skill + Executor + 契约 + 上下文 + 进度
3. **并行工具调用** — `parallel_tool_calls=True` 允许同时调用多个工具
4. **进度追踪** — checkpoint/reflect 重试时不会重复执行已完成步骤
5. **两级降级** — ReAct 失败 → 旧版 Skill → 错误信息
6. **契约是边界** — scope.out / constraints / risks 在 Prompt 中明确标注

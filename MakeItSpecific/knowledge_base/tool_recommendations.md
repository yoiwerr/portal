# 工具推荐库

阿福在引导用户时，根据任务类型推荐合适的工具。以下是内置工具推荐清单。

## 代码编写与实现

| 工具 | 适用场景 | 推荐理由 |
|------|---------|---------|
| **Claude Code** | 写代码、改 bug、重构、项目搭建、代码审查 | 深度理解代码库，可直接读写文件，支持终端命令；阿福理清需求后，用户把任务契约带给 Claude Code 即可开始编码 |
| **Cursor** | 写代码、重构、逐文件修改 | IDE 集成，适合需要实时看到代码变动的场景 |
| **GitHub Copilot** | 补全代码、生成函数 | 轻量代码补全，适合日常开发辅助 |
| **CodeRabbit** | 全量 PR 审查 | 自动扫描整个 PR，适合大项目代码审查 |

## AI 对话与深度研究

| 工具 | 适用场景 | 推荐理由 |
|------|---------|---------|
| **ChatGPT** | 深度技术研究、联网搜索、多轮追问 | 知识面广，支持联网，适合需要广泛调研的问题 |
| **Perplexity** | 快速查资料、找文档、搜技术方案 | 搜索精准，标注来源，适合技术决策前查证 |
| **Google** | 查最新文档、版本发布、社区讨论 | 最直接的原始信息源 |

## UI 与设计

| 工具 | 适用场景 | 推荐理由 |
|------|---------|---------|
| **Figma** | UI 设计、原型、设计系统 | 行业标准设计工具 |
| **Claude** | 生成页面原型、HTML/CSS 设计 | 可直接输出代码级设计，适合快速验证 |
| **v0 / Bolt** | 从描述直接生成前端页面 | AI 驱动的界面生成工具 |

## 数据分析

| 工具 | 适用场景 | 推荐理由 |
|------|---------|---------|
| **ChatGPT Code Interpreter** | 数据分析、图表绘制、CSV 处理 | 内置 Python 环境，可跑代码 |
| **Jupyter Notebook** | 探索性数据分析 | 适合需要反复调试的分析任务 |

## 项目管理与协作

| 工具 | 适用场景 | 推荐理由 |
|------|---------|---------|
| **Linear** | 任务跟踪 | 简洁高效的项目管理 |
| **Notion** | 文档协作、知识管理 | 灵活的文档+数据库 |
| **Obsidian** | 个人知识管理 | 本地 Markdown，适合长期积累 |

## 推荐原则

1. **先理清需求，再推荐工具** — 不要让用户觉得"我不知道要什么，你先给我一堆工具列表"
2. **一次推荐不超过 3 个** — 选择太多等于没选
3. **解释为什么选这个** — 不是"用 Claude"，而是"用 Claude Code，因为它可以直接读写你的文件，阿福已经帮你理清了需求，你只需要把契约带过去"
4. **阿福的角色** — 阿福帮你理清思路、发现遗漏、制定计划、生成任务契约。然后你带着这份清晰的契约，去找推荐的工具执行
